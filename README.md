# 🎬 Netflix Movies & TV Shows Analysis – Power BI

## 📌 Project Overview

This project presents an interactive **Netflix Movies and TV Shows Analysis Dashboard** developed using **Microsoft Power BI**.

The objective of this project is to analyse Netflix titles based on their type, release year, IMDb ratings, IMDb votes, runtime, and age certification.

The dashboard provides interactive visualizations that help explore content trends and understand how Netflix movies and shows vary across different dimensions.

## 📊 Dashboard Analysis

The Power BI report contains three analysis pages.

### 1. Movie Analysis

This page focuses on movie-level analysis and includes:

* Movie title and rating analysis
* Number of movies by release year
* Average IMDb score by release year
* IMDb votes by release year
* Average movie runtime by release year
* Movie type filtering
* Release year filtering

---

### 2. Age Certification Analysis

This page analyses the relationship between:

* Age Certification
* Average IMDb Score

The visualization helps compare IMDb performance across different age-certification categories.

---

### 3. Netflix Movies & TV Shows Dashboard

The main dashboard provides an overview of Netflix content using:

* Number of Shows and Movies
* Rating analysis
* IMDb score trends
* IMDb votes trends
* Runtime trends
* Number of titles by release year
* Age certification analysis
* Interactive Type filter
* Interactive Release Year filter

---

## 📈 Key KPIs & Metrics

The dashboard uses several important analytical metrics, including:

* **Number of Shows and Movies**
* **Average IMDb Score**
* **IMDb Votes**
* **Average Runtime**
* **Rating × Votes**

These metrics help evaluate the quantity, popularity, and performance of Netflix content.

---

## 🔍 Key Business Questions

This dashboard helps answer questions such as:

1. How has the number of Netflix titles changed over the years?
2. How has the average IMDb score changed over time?
3. How does IMDb voting activity vary across release years?
4. How does average runtime change over time?
5. Which titles have stronger rating × vote performance?
6. How do IMDb scores vary across age certifications?
7. How does content differ between movies and TV shows?
8. How can users filter Netflix content by type and release year?
